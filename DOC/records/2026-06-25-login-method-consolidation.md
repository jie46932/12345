# 2026-06-25 登录方式收敛与微信扫码登录经验

## 本次结论

- 12345 项目删除“微信扫码登录”作为默认登录方式。
- 默认登录方式改为：
  - 短信验证码登录
  - 账号密码登录
- 微信开放平台“网站应用扫码登录”不适合手机微信内打开页面后长按识别同页二维码。

## 微信扫码登录踩坑记录

### 现象

手机微信打开 `https://hefurniture.gsdmsj.cn/` 后，长按页面中的微信登录二维码，会出现微信提示：

- 该二维码仅支持在扫一扫时，通过摄像头来识别
- 暂不支持通过长按图片、扫一扫时从相册读取图片等方式来识别

如果把微信 `qrconnect` 登录地址再转成普通二维码图片，用户扫码后会进入“微信登录”二级二维码页面，而不是直接出现确认登录页。

### 原因

微信开放平台“网站应用扫码登录”二维码是面向 PC/另一设备扫码的流程。

它的正确使用方式是：

1. 电脑或另一台设备打开网页。
2. 网页显示微信官方 `qrconnect` 二维码。
3. 手机微信使用“扫一扫”摄像头扫描网页上的二维码。
4. 手机端出现确认登录页。

不适合的方式是：

- 在手机微信内打开同一个网页。
- 长按识别页面中的二维码。
- 把 `qrconnect` URL 自己生成一张二维码图片并期望手机微信直接确认登录。

### 后续复用建议

- 如果需要“手机微信内一键登录”，不要使用网站应用扫码登录，应改用公众号网页授权或小程序授权链路。
- 如果需要“桌面网站微信扫码登录”，可以继续使用微信开放平台网站应用 `qrconnect` 官方 iframe。
- 如果项目主要面向手机访问，优先使用短信验证码登录。
- 如果必须保留微信能力，建议把它作为桌面端可选登录方式，不作为手机端默认方式。

## 当前实现状态

- 前端登录页只展示：
  - 短信验证码登录
  - 账号密码登录
- 服务器新增独立短信登录接口：
  - `POST /api/sms-login/send`
  - `POST /api/sms-login/verify`
- 短信验证码由后端生成、保存哈希并本地核验。
- 阿里云只负责发送验证码短信，不再负责核验验证码。

## 关键环境变量

- `ALIYUN_SMS_SIGN_NAME`
- `ALIYUN_SMS_TEMPLATE_CODE`
- `ALIYUN_SMS_SCHEME_NAME`
- `ALIYUN_SMS_ENDPOINT`
- `ALIYUN_DYNSMS_REGION`

密钥类变量只允许存在于服务器环境文件中，不写入前端、Git、README 或部署产物。
